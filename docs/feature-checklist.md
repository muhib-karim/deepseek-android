# Account feature verification

All verification below is against a mocked server only. Tests were authored before implementation, but compilation, execution and screenshot generation are pending GitHub Actions; no local Gradle/build was run. Real-account login has not been tested. No claim of live DeepSeek compatibility is made.

`AccountFeaturesTest` uses the real AccountViewModel, UI, encrypted stores and HTTP client with MockWebServer and an injected fast PoW solver. Every method runs in both Light and Dark and saves an `official-ui-screenshots` capture through the helper shared with `OfficialScreenshotsTest`. Only the system picker URI, speech recognizer and remote service are substituted. API fallback uses the existing chat UI with its client pointed at the mock server. Google navigation is blocked before any request to Google.

1. New chat — `AccountFeaturesTest.feature01_newChat`: empty composer/messages, distinct remote sessions, previous chat retained.
2. Send and incremental reply — `AccountFeaturesTest.feature02_sendStreaming`; `AccountStreamTest.preservesBothServerMessageIdsAndIncrementalThinkingAndAnswer`: observe partial text before the final response and inspect the prompt request.
3. Stop — `AccountFeaturesTest.feature03_stop`; `AccountTransportTest.cancellationClosesABlockedStreamAndAllowsTheNextRequest` and `cancellationClosesAnInitialRequestWithoutWaitingForReadTimeout`: retain partial text, cancel transport, send again with a valid predecessor.
4. History — `AccountFeaturesTest.feature04_history`; `AccountTransportTest.renameAndDeleteUseRemoteSessionIdsAndAuthenticatedJson` and `mutationsAcceptExplicitNullAcknowledgementsButStillRequireTheEnvelope`: list/open, rename dialog, delete confirmation/cancel, remote bodies, disk synchronization and server-failure rollback.
5. DeepThink — `AccountFeaturesTest.feature05_deepThink`; `AccountStreamTest.preservesBothServerMessageIdsAndIncrementalThinkingAndAnswer`: request flag and expanding/collapsing actual thinking fragments.
6. Search — `AccountFeaturesTest.feature06_search`; `AccountTransportTest.regenerateAndEditedBranchesKeepExplicitPriorAssistantAndModeAndFileReferences`: per-send confirmation and search_enabled body.
7. Attachments — `AccountFeaturesTest.feature07_attachment`; `AccountTransportTest.uploadUsesMultipartBytesNameAndMimeAndAcceptsBothIdShapes`: real document/blank-image import, visible chip, multipart bytes and ref_file_ids.
8. Microphone — `AccountFeaturesTest.feature08_voice`; existing `DictationSessionTest`: composer button, runtime permission path with a granted permission, fake results in draft, unavailable notice, one-shot voice shortcut and rejection of late callbacks after changing chat. Permission-denial notice is implemented; a real device permission dialog/recognizer has not been exercised here.
9. Markdown and code copy — `AccountFeaturesTest.feature09_markdownCopy`; existing `MarkdownParserTest`: rendered heading/code and actual Android clipboard contents.
10. Message actions — `AccountFeaturesTest.feature10_messageActions`; `AccountTransportTest.regenerateAndEditedBranchesKeepExplicitPriorAssistantAndModeAndFileReferences`; `WebHistoryTest.branchingMetadataAndAttachmentReferencesSurviveRestart`: user/assistant clipboard, regeneration, edits at first/later turns, predecessor IDs, later-turn replacement and preservation of custom titles.
11. Settings — `AccountFeaturesTest.feature11_settings`; existing `SessionStorageTest`: persisted System/Light/Dark theme, encrypted API-key enter/clear, real API chat UI and return, shared key refresh, logout to login with token/cookies/history cleared.
12. Login WebView — `AccountFeaturesTest.feature12_loginWebView`; existing `WebViewBoundaryTest`: login action, mock sign-in HTML loaded into the real restricted WebView, Google navigation blocked with the specified message. Loopback HTTP is enabled only by a debug resource; release remains HTTPS-only.
13. Expiry — `AccountFeaturesTest.feature13_sessionExpiry`; `AccountTransportTest.everySessionExpiryEnvelopeLocationHasTheExactSafeMessage` and `allNewRemoteActionsPropagateSessionExpiry`; `AccountStreamTest.authCodesInsidePatchValuesAndBusinessDataRequireSignIn`: HTTP 401 and root/business/SSE 40001/40002/40003 clear the account session and return to login with the exact notice.
14. Changed endpoints — `AccountFeaturesTest.feature14_endpointChange`; `AccountTransportTest.unexpectedHttpAndMalformedRequiredEnvelopesHaveTheExactSafeMessage`, `malformedUploadShapeAndChallengeCannotBecomeSuccess`, `malformedStreamAndBusinessExpiryAreTypedThroughTheTransport`, `anHttpBodyTruncatedDuringAStreamIsATypedProtocolFailure`; `AccountStreamTest.malformedResponseFieldsAndFramingAreSafeTypedFailures`; `PowTest.malformedChallengeFieldTypesAreTypedAndSanitized`: typed, sanitized errors for unexpected HTTP/schema/stream changes and access to explicit API fallback.
