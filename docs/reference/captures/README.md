# Official reference captures

Reviewed, sanitized captures from the **Official DeepSeek reference** workflow (`.github/workflows/reference.yml`) go
here, one PNG, one sanitized hierarchy (`.xml`) and one metadata file (`.json`) per screen and theme, named
`<theme>-<screen>` with the IDs from [../SCREEN_SPEC.md](../SCREEN_SPEC.md).

None are committed yet: the workflow has not run (it needs a push and a manual dispatch). Until then the workflow's
`deepseek-official-reference` artifact is the only place captures exist. Captures show DeepSeek's own interface and are
kept for comparison only; they are never packaged into the app.
